### Installation

`cargo install rust-i18n`

Now `cargo i18n` should collect strings to translate.

**Unfortunately** not from .html templates, so currently that part is done manually.

## Translation strings in .html - how to

Most of the time you'd want something like this

```
<?= t!("messages.hello") ?>
```

or with args

```
<?= t!("messages.hello", username=user.name, nonce=nonce) ?>
```

with HTML inside the translated strings use `<?-` (unescaped) instead of `<?=`

**IMPORTANT:** NEVER (!) do this if part of the message is provided by the users!

```
<?- t!("messages.hello", username=user.name, nonce=nonce) ?>
```

For example `t!("Hello %{name}", name=user.name)` could lead to injection attacks;
The CSP is fairly strict, but let's not introduce unnecessary risk.
